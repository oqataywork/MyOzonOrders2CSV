# OzonMyOrders2csv

Расширение Chrome для выгрузки истории заказов покупателя Ozon в CSV для Excel.

Это форк [soft4life/MyOzonOrders2CSV](https://github.com/soft4life/MyOzonOrders2CSV) с исправлениями безопасности и новым интерфейсом. Версия **0.9.0**, основа — коммит `caa0e1e3be96c2bfc40552261377f488eee67756`. Требуется Chrome 116 или новее.

## Новый интерфейс 0.9.0

- Нажатие значка открывает боковую панель и [архив заказов Ozon](https://www.ozon.ru/my/orderlist?selectedTab=archive). Уже открытая вкладка архива используется повторно; другие вкладки не заменяются. При запуске браузера расширение само ничего не открывает.
- По умолчанию выбран период **от этой даты месяц назад до сегодня**. Например, 16 ноября — с 16 октября по 16 ноября включительно. Короткие месяцы учитываются: 31 марта → 28 или 29 февраля.
- Быстрый выбор недели, месяца, года и всей истории. Для текущего года верхняя граница — сегодня, для прошлого — 31 декабря. Ручные даты сохраняются; относительные периоды пересчитываются при открытии и запуске выгрузки.
- Отдельные режимы «За период» и «Один заказ». Настройки возвратов, вкладок и кэша свёрнуты и не мешают обычному запуску.
- Прогресс, время обработки, результат и остановка доступны в панели. Она отслеживает исходную вкладку заказов даже при переключении на другие страницы. После остановки можно сохранить собранное или завершить без файлов прямо из панели.
- Сохранён прежний сбор заказов через страницы Ozon: вкладки, разбор DOM и резервные запросы. Дополнительных серверов, библиотек и внешних ресурсов интерфейса нет.

## Исправления безопасности

- Формулы в текстовых ячейках CSV обезвреживаются префиксом табуляции внутри кавычек. Проверяются также начальные пробелы, невидимые символы и полноширинные знаки формул. Префикс остаётся частью данных при программном импорте; универсальной защиты для всех табличных редакторов и повторных преобразований CSV нет.
- Ссылки принимаются только на `https://ozon.ru` и `https://www.ozon.ru`, без логина, пароля и нестандартного порта. Страницы заказа и возврата проверяются перед открытием. Резервные HTTP-запросы не следуют перенаправлениям.
- Разрешения `tabs` и `activeTab` не используются. Нужны `storage`, `downloads`, `sidePanel` и доступ к двум доменам Ozon. `sidePanel` отвечает за боковую панель Chrome.
- Галочка «Использовать и сохранять кэш» выключена при новой установке. Когда она снята, экспорт не читает и не записывает историю заказов в кэш. Существующие записи не удаляются автоматически; используйте кнопку «Очистить». Настройки дат и режима сохраняются отдельно.

Подробности проверки, ограничения и источники: [SECURITY-REVIEW.md](SECURITY-REVIEW.md). Исправления проверены на искусственных данных; выгрузка из реального аккаунта Ozon и открытие CSV в Excel не проверялись.

## Возможности

- Выгрузка выбранного периода, полного года или конкретного заказа по номеру/ссылке.
- Отдельная строка на товар: количество, цена, реальная цена, сумма позиции и заказа.
- Проверка возвратов; возможность включить товары с заявкой на возврат.
- Необязательный кэш закрытых заказов. При выключенном кэше заказы читаются с Ozon без сохранения истории в профиль Chrome.
- Наблюдаемый режим обработки вкладок, остановка с сохранением частичного CSV и отчёта.
- Сохранение CSV и JSON через «Сохранить как» с проверкой завершения загрузки.

## Установка и обновление

1. Скачайте `OzonMyOrders2csv_0.9.0.zip` из [релизов этого форка](https://github.com/oqataywork/MyOzonOrders2CSV/releases/latest) и распакуйте в постоянную папку `OzonMyOrders2csv`.
2. Откройте `chrome://extensions`, включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
4. При обновлении замените файлы в этой папке, нажмите «Обновить» у расширения и перезагрузите страницу Ozon.

Проверка и сборка из исходников (Node.js 22+; зависимостей npm нет):

```powershell
npm test
npm run check
powershell -NoProfile -File scripts/package.ps1
npm run test:browser
```

Готовая папка появится в `dist/OzonMyOrders2csv`, ZIP и его SHA-256 — рядом в `dist`. Можно загрузить в Chrome именно эту папку. Автоматического обновления с исходного репозитория нет.

Необязательная команда `test:browser` проверяет готовую папку в отдельном пустом профиле современного Chrome через CDP. По умолчанию используется стандартный путь Chrome в Windows; другой путь задаётся переменной `CHROME_PATH`. В тесте сетевые обращения страниц подменяются искусственным HTML, внешний HTTP-доступ блокируется локальным прокси. Вход в аккаунт не нужен. `OZON_CAPTURE_UI=1` дополнительно сохраняет снимок интерфейса в `dist/ui-preview.png`.

## Использование

Нажмите значок расширения: архив заказов откроется автоматически рядом с панелью. При необходимости войдите в Ozon и нажмите ↗ в панели для повторного подключения. Оставьте последний месяц или выберите свои даты, затем нажмите **«Скачать CSV»**. Для одного заказа переключитесь на «Один заказ» и введите номер или ссылку.

Не закрывайте вкладку архива до завершения. Саму панель можно закрыть и открыть снова: прогресс восстановится из вкладки. При остановке появятся кнопки «Сохранить собранное» (CSV и диагностический JSON) и «Завершить без файлов». Папку сохранения выбирайте в диалоге Chrome.

CSV использует UTF-8 и разделитель `;`. Отменённые товары исключаются. Подробные правила цен, возвратов и кэша приведены в [README.txt](README.txt).

## Изменения 0.8.14–0.8.26

- Проверка фактического завершения скачивания; отображение отмены и ошибок сохранения.
- Изоляция строк итогов: бесплатная доставка больше не заимствует сумму товаров из соседней строки. Кэш переведён на схему v4.
- Предустановка полного календарного года с сохранением дат.
- Проверка подтверждённой даты перед обновлением записи кэша: другие периоды не изменяются.

## Данные и ограничения

Данные обрабатываются локально; расширение обращается к Ozon с текущей сессией браузера. В проверенном коде не обнаружена отправка истории заказов на сторонние серверы. CSV, экспорт кэша и диагностический JSON могут содержать сведения о покупках и номера заказов. Разметка Ozon может меняться. Автоматические проверки не заменяют проверку результата на реальном заказе.

## Загрузка истории

Числового ограничения прокруток нет. Автозагрузка продолжается до границы периода по датам получения в списке, конца списка или ручной остановки. Дата заказа для фильтрации берётся со страницы заказа. Без даты «от» история загружается до конца списка.

Цена распознаётся с группами тысяч: число из названия продавца не присоединяется к сумме. Подозрительная запись кэша с ценой товара выше итога перечитывается с Ozon; остальные записи сохраняются.

Граница рекомендаций распознаётся по отдельным текстовым блокам, а не только HTML-заголовкам. Для ранее выгруженных заказов с лишними товарами выполните выгрузку без использования кэша.

Наличие рекомендаций на странице списка не останавливает загрузку истории. Остановка списка определяется датами, прекращением прокрутки или кнопкой «Стоп». Фильтрация рекомендаций внутри отдельного заказа сохраняется.

История прокручивается с перекрытием экранов и паузой 2 секунды. Конец списка подтверждается шестью проверками без изменения позиции, высоты страницы и числа найденных заказов. Во время ожидания доступна кнопка «Стоп».

После прохождения последней загруженной карточки заказа прокрутка приостанавливается. Если за шесть проверок новые заказы не появляются, сбор списка завершается независимо от роста ленты рекомендаций.

Прокрутка прекращается при достижении отображаемого блока рекомендаций, в том числе «Подобрали по вашим интересам». Наличие этого блока ниже экрана само по себе не останавливает загрузку.

При сборе истории проверяется видимость всей карточки заказа, а не только ссылки внутри неё. CSV содержит отдельную причину остановки у рекомендаций или после ожидания подгрузки.

Версия 0.8.26: механизм загрузки истории восстановлен из опубликованного GitHub-релиза с тегом Ozon, без числового лимита прокруток. Используются шаг 82% экрана, пауза 850 мс и проверка заголовков рекомендаций h1–h3. Последние изменения ожидания и остановки после карточек отменены.

В 0.8.27 цены читаются из минимальных DOM-блоков с денежной суммой, без присоединения цифр из названия продавца. Подтверждённая прокрутка 0.8.26 сохранена.
